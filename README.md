# SoundPulse · Spotify v0.1.1
Первый прототип для SillyTavern. Требует установленный и авторизованный официальный Spotify extension.

Есть: плавающий винил, текущий трек/обложка/прогресс, управление playback, цвет от обложки, Auto/In-world/Soundtrack/Visual, Music Awareness. Lyrics-слот подготовлен, но источник lyrics пока не подключён.


0.1.1: исправлена ошибка инициализации панели настроек, из-за которой виджет не создавался.
